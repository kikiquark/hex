# Hex

Игра Гекс против нейросети в духе AlphaZero: 8 ступеней сложности (классические алгоритмы и нейросеть той же силы), поля от 6×6 до 14×14, работает прямо в браузере и без интернета.

Играть: https://kikiquark.github.io/hex/

Здесь только собранная игра; сборка из исходников проекта, версия 86b7c5a.
